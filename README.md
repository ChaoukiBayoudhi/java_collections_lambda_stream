# Java collections lambda stream

A Java console application.

## Tech stack

- Java (no build tool: plain source files)

## Concepts covered

Abstract classes, collections, console input (Scanner), inheritance, interfaces.

## Project structure

- `Classes`: Note, Person, Student
- `Classes.Abstracts`: RectangleTable, RondeTable, Table
- `Classes.Implementation.Collections`: StudentList, StudentMap, StudentSet
- `Interfaces`: IStudent
- `src`: Main

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Main` (it contains the `main` method).
